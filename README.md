# HR Analytics & Employee Management System

An advanced HR Analytics and Employee Management System developed using **Microsoft Excel and VBA (Visual Basic for Applications)**. This project automates HR operations, manages employee records, tracks attendance, processes payroll, and provides interactive dashboards for data-driven HR decision-making.

## Project Overview

The system is designed to simplify HR management activities through Excel VBA automation and interactive reporting.

## Key Features

- Employee Information Management
- Employee Registration and Profile Management
- Attendance Tracking System
- Leave Management System
- Payroll Processing and Salary Calculation
- Employee Performance Analysis
- Department-wise Employee Analysis
- Automated HR Reports
- Interactive Excel Dashboard
- VBA-based Automation and UserForms
- Search, Update and Delete Employee Records

## Technology Stack

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Data Validation
